# E14 — Мультиязычность (i18n)

**Приоритет:** — | **Фаза:** 6 | **Статус:** ❌ cancelled

## Решение

Сайт **English-only**. RU+EN / next-intl / language switcher **не реализуем**.

Причины:
- продукт и UI уже на английском (`lang="en"`);
- повторное требование заказчика / команды: не добавлять русский.
