# E19.2 — Admin API (NestJS)

**Статус:** ✅ Готово | **Оценка:** ~10 ч | **Приоритет:** P0 | **Зависимости:** E19.1 (parallel ok)

## Цель

Единый `AdminModule` с REST под `/api/admin/*`, защищённый JWT + ролями (не только `X-Admin-Key`).

- [x] **E19.2.3** — `POST /api/admin/auth/login` — reuse `AuthService.login` + role check (403 для CUSTOMER) (2ч)
