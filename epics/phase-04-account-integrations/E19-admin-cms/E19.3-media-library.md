# E19.3 — Медиа-библиотека

**Оценка:** ~10 ч | **Приоритет:** P0 | **Зависимости:** E19.2 | **Статус:** ✅

## Цель

Загрузка и переиспользование изображений в формах (обложка блога, акции, фото авто, баннеры) без ручных URL.

## Подзадачи

- [x] **E19.3.1** — Prisma `MediaAsset` (id, url, filename, mime, size, alt, folder, createdAt)
- [x] **E19.3.2** — `POST /api/admin/media/upload` (multipart) — local `/uploads`
- [x] **E19.3.3** — `GET /api/admin/media`, `DELETE /api/admin/media/:id` (+ usage warning)
- [x] **E19.3.4** — UI: `/admin/media` grid + Media picker modal в `AdminImageUpload` / gallery

## v1 storage

| Окружение | Хранилище |
|-----------|-----------|
| Docker dev | `backend/uploads/` + static serve `/uploads/*` |
| Production | Env `S3_*` или Cloudinary (решить при E0.3.2) |
