# E19.1 — Admin shell: layout, auth, design system

**Статус:** ✅ Готово (v1) | **Оценка:** ~12 ч | **Приоритет:** P0 | **Зависимости:** E11.1 (JWT auth)

## Цель

Отдельная зона `/admin` с понятной навигацией и единым визуальным языком (Suzuki navy/red, не «сырой» Bootstrap).

## Подзадачи

- [x] **E19.1.1** — Route group `frontend/src/app/admin/` + `AdminShell` (sidebar, topbar) (4ч)
- [x] **E19.1.2** — Страница `/admin/login` (staff login, redirect if unauthenticated) (2ч)
- [x] **E19.1.3** — Admin UI на Tailwind v4 + токены Suzuki (`--suzuki-navy/blue/red`) вместо отдельного design-system файла (3ч)
- [ ] **E19.1.4** — Shared components: `AdminTable`, `ConfirmDialog`, `Toast` — сейчас `confirm()`/инлайн-таблицы; вынести в переиспользуемые компоненты при добавлении E19.4/E19.6 (3ч)
